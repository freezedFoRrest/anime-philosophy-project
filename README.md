# Философия в аниме

Учебный многостраничный сайт на чистых HTML, CSS и JavaScript.

## Запуск

Можно открыть `index.html` напрямую или запустить локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Перед сдачей

1. Замените учебные данные «Соколов Артём, 2005» и группу «БЭК-01» на свои в `forms.html`, `dom.html` и `transliteration.html`.
2. В проекте реализован вариант алгоритмической задачи 1008.
3. Если преподаватель требует скриншот именно с вашими данными, обновите `assets/dom-screenshot.svg`.

## Проверка требований

- единая навигация, текстовая и графическая ссылка на главную, активный пункт;
- ссылка на внутренний фрагмент и внешние ссылки в новой вкладке;
- 6 информационных страниц и 3 отдельные страницы заданий JS;
- нумерованные, ненумерованные и вложенные списки;
- пояснённые изображения и миниатюры-ссылки на изображения 600 × 400;
- таблица с фоновым изображением, изображениями в ячейках и ссылками;
- контактная форма и тематическая форма с обязательными типами полей и значениями по умолчанию;
- чтение данных из DOM, изменение текста по клику и алгоритмическая задача.
